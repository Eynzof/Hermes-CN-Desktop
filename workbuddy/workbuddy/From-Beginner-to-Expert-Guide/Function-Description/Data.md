# 数据管理

管理已分享的文件和已归档的任务，入口为**头像-设置-数据管理**。

![](https://www.codebuddy.cn/docs/static/data-1.Ca0Gnduq.png)

## 我分享的文件

将任务的产物分享后，文件会出现在已分享的文件列表中：

![](https://www.codebuddy.cn/docs/static/data-2.DM1YKxY_.png)

在**我分享的文件中**可以复制文件分享链接、下载文件和取消文件分享。取消分享后，文件从列表中移除，他人无法再通过链接访问。

![](https://www.codebuddy.cn/docs/static/data-3.YA-5Ao9s.png)

## 已归档任务

将任务列表**归档**后，任务会出现在已归档任务列表中：

![](https://www.codebuddy.cn/docs/static/data-4.B2kU8_30.png)

**已归档任务**列表支持删除任务或取消归档：

![](https://www.codebuddy.cn/docs/static/data-5.BTuwGfER.png)

- **删除任务：** 删除任务会弹窗进行二次确认，任务删除后不可查看和继续对话。
- **取消归档：** 取消归档后任务将恢复到**任务列表**。
