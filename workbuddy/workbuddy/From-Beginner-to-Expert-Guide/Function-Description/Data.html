数据管理 ​

管理已分享的文件和已归档的任务，入口为头像-设置-数据管理。

我分享的文件 ​

将任务的产物分享后，文件会出现在已分享的文件列表中：

在我分享的文件中可以复制文件分享链接、下载文件和取消文件分享。取消分享后，文件从列表中移除，他人无法再通过链接访问。

已归档任务 ​

将任务列表归档后，任务会出现在已归档任务列表中：

已归档任务列表支持删除任务或取消归档：

  • 删除任务： 删除任务会弹窗进行二次确认，任务删除后不可查看和继续对话。
  • 取消归档： 取消归档后任务将恢复到任务列表。
