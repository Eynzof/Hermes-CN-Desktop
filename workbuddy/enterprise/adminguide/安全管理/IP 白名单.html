腾讯云代码助手提供了企业 IP 白名单配置功能，使企业能够通过 IP 限制插件的使用范围。

说明：

适用版本：旗舰版、专享版、企业版。

在 企业设置 > 网络设置菜单当中，配置企业的 IP 白名单，IP 白名单作用于代码助手插件，被限制的 IP 将无法登录插件并使用。

IP 限制的生效规则如下：

  • 多个 IP 用英文逗号隔开，逗号前后不加空格。

  • 仅设置127.0.0.1代表禁止所有 IP 访问。

  • 不填写则代表允许所有 IP 访问。

  • 设置 IP 段例如10.10.10.0/24代表允许该网段访问。
