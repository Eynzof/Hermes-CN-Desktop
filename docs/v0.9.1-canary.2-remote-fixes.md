# v0.9.1-canary.2 远程连接修复

本候选基于 v0.9.0 白屏修复分支，保持内置 Core 0.21.0-cn.18、应用 identifier 和 runtime schema 不变，仅供定向验收。

- 外部本地或远程连接的内核版本取实际目标 `/api/status`，不显示本机随附内核的版本及提交。
- 当前会话、网关会话 ID 与持久会话映射按连接模式和目标地址隔离。保留内置模式原有状态；无法判定归属的旧版外部自动恢复标记不迁移到任何远端，会话历史继续从目标后端读取。
- 切换连接前等待 UI 状态写入并关闭旧 WebSocket；切换失败时恢复原连接。成功后沿用现有界面重载流程。

验收重点：原版 v0.9.0 覆盖安装后恢复白屏且数据保留；原版外壳通过生产签名 UI 热更新获得相同修复；内置与两个独立远端之间切换、刷新和重启不产生跨目标会话。

不修改 Landing、公共 stable/canary 清单和 GitHub latest，不执行全量发布。Windows 安装器系统 Authenticode 与 UI Ed25519 签名是两种独立机制，验收记录分别说明实际状态。
