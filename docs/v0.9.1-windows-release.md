# v0.9.1 Windows 修复版

本次仅准备 Windows x64 安装版、免安装版及 Windows UI 热更新。正式版本的业务代码与已在 Enzo-Win 验收的 `c1268d38d2f54dbec01fd379071cbfea76637905` 相同，仅同步版本号与发布说明。

## 修复内容

- 兼容远程官方 CLI 内核缺少 `/api/version` 的情况，读取 `/api/status`，避免连接后白屏。
- 远程模式的内核版本显示来自实际连接的服务，不再显示本机随附内核版本。
- 按连接模式、服务地址与路径隔离会话选择和映射；切换连接时关闭旧网关，避免把一个服务的会话带到另一个服务。

## 发布边界

- 内核固定 `runtime-v0.21.0-cn.18`，Core 提交 `b9f82a21fd9268bd499051e23b614ecb06d5b888`。
- bundle identifier 仍为 `cn.org.hermesagent.desktop`；runtime manifest schema 仍为 2。
- Windows UI 更新最低外壳版本为 `0.9.0`，由原生产 Ed25519 密钥签名。
- 安装器使用原生产 Tauri 更新签名；未添加 Windows Authenticode 证书。
- macOS、Linux 继续使用既有 `0.9.0` 包，本次未重新构建或验收。
- 发布准备只创建 GitHub Release 草稿和版本化资产；公开 stable 更新清单、GitHub Latest、官网和生产灰度配置需在发布时同步启用。

## 升级说明

覆盖安装前请从系统托盘退出正在运行的 Hermes 桌面端。使用安装器覆盖原目录，无需先卸载。免安装版退出后覆盖解压，保留 `data` 目录。

Windows 可能显示 SmartScreen 提示，请核对下载来源与 SHA-256。Tauri 更新签名与 Windows Authenticode 是不同机制。

UI 热更新只替换界面，不升级本地或远程内核。已经白屏而无法进入设置的用户可使用完整安装包恢复。

## 验收依据

前置灰度已验证原版 0.9.0 的真实覆盖安装、生产签名 UI 更新、远程官方 0.22 连接、托管与两个远程服务间的会话隔离、退出重启与会话继续；64 项针对性测试及类型检查通过。正式版本另记录构建身份、签名、资产散列与最小真机复测结果。
