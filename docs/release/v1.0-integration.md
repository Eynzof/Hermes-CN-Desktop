## 0.9.3 过渡行为

整包安装器会一起替换外壳和随附内核。整包检查保持目标版本、渠道、资产 URL、平台、摘要、大小及签名检查，并核对目标 Core 与 runtime 基础版本一致。检查整包目标时使用目标元数据中的版本。独立内核更新继续按当前外壳的兼容表检查，因此 0.9.3 仍仅接受 0.21 内核。

旧版自动升级路线为 0.9.0／0.9.1 → 0.9.3 → 1.0.0。发布服务的过渡路由仍待离线整合和验证，投放前需要对应平台和渠道的 0.9.3 记录。
