模型使用用户授权的 DeepSeek 官方 `deepseek-v4-flash`，本地夹具仅用于更新服务故障场景，不代理模型请求。保留了托盘操作、测试基线 BOM、模型从 501 开始输出导致脚本误判等原始失败记录；改正脚本后只补跑对应范围。

Windows 当前 RC4 精确基线为 7 项通过、82 项本轮未跑、4 项既有豁免、8 项隐藏；升级流程采用单独 RC1 基线，不能将跨版本历史通过数拼成 RC4 全覆盖。Mac UI 测试仍有人工/视觉阶段，未完成全部无人值守脚本化。

## 交付位置和分发边界

本地交付根目录：`artifacts/v090-rc4-20260917/`（位于 CNDesktop 工作区根）。

- `release-assets-local/`：两平台安装包、更新签名资产、Core ZIP 与 schema 2 清单，共 9 文件。
- `SHA256SUMS.txt`、`artifacts-index.json`：最终产物大小和摘要。
- `RC-TEST-GUIDE.md`、`RC-ACCEPTANCE.md`、`RC-KNOWN-ISSUES.md`：人工指南、证据索引与未覆盖项。
- `windows-native/runs/`：真实安装包的 HTML/JSON 报告及实际运行的框架源码快照。

目前仅通过本地功能门槛。Tauri/Runtime 为测试更新密钥；Mac 有 Developer ID 但没有公证，Windows 没有 Authenticode；正式 canary 服务及邀请未验收。需要正式签名、最终服务和旧公开版本升级验收后，才能进入分发。RC 不修改 Landing、stable 或公开 `latest.json`。

Mac 锁屏时临时证书的用户信任规则未能完成系统认证删除，证书本体与夹具进程已清理；交付目录提供只移除该确切规则的脚本及证据。Core #136 继续按用户要求跳过，#141 原始微信场景、Intel/macOS 12、Ubuntu 22.04 等未覆盖项保留在已知限制中。
