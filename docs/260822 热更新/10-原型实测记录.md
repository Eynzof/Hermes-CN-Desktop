## 4. 构建网络问题与解决

### 观察

- Windows Rust/前端首次完整编译成功。
- Tauri NSIS 从 GitHub 下载阶段超时：`failed to bundle project timeout: global`。
- `workers.dev` 从测试机超时。

### 处理

- 根据 Tauri 官方 bundler 源码，在 Mac 下载 `nsis-3.11.zip` 和 `nsis_tauri_utils.dll`，核对官方固定 SHA-1，传入 `%LOCALAPPDATA%\tauri\NSIS` 缓存。
- 预热后 NSIS 打包成功。
- 客户端更新入口改用自定义 staging 域名；该机健康检查、清单和 Range 均成功。
- Tauri 自动 build 签名在 PowerShell 空密码/私钥变量处理上会交互等待，最终采用 Windows 构建 + 隔离 Mac 执行 `tauri signer sign --password ''`。

这证明缓存和自定义域名可以解决本机问题，但不能替代多运营商测试。
