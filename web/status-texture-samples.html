在线项目参考

扩展方案主要借鉴这些项目的“可重复 SVG 单元、尺度可调、低对比纹理”方法。CSS 渐变类项目只用于观察图案分类，不采用其渐变实现。

Pattern Monster可调 SVG 无缝纹理生成器，图案数量丰富。 Hero Patterns适合网页背景的可重复 SVG 图案集合。 PatternFills面向状态与图表区分的 SVG pattern fill。 GeoPattern根据字符串种子生成平铺 SVG 几何纹理。 CSS Pattern大规模图案分类参考；本方案不采用其渐变实现。 BGJar在线生成可导出的 SVG 背景与覆盖纹理。
